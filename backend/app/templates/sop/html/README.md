# HTML Templates (Simple Version)

This folder contains simplified HTML templates that don't require Jinja2.

These are static HTML templates that can be filled with data using simple string replacement or client-side JavaScript.

## Usage

For simple use cases where you don't need server-side templating, you can use these HTML files directly.

## Template Files

- `spc_report_simple.html` - Basic SPC report template
- `fdc_report_simple.html` - Basic FDC report template  
- `rca_onepager_simple.html` - Basic RCA template

## Note

For production use, we recommend using the Jinja2 templates in the `jinja2/` folder as they provide better flexibility and maintainability.
